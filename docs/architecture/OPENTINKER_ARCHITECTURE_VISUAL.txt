DATA FLOW IN ONE TRAINING STEP
================================================================================

1. Client sends batch to Training Server
   ────────────────────────────────────
   DataLoader → DataProto → POST /api/v1/train_step

2. Training Server generates responses (multi-turn)
   ─────────────────────────────────────────────────
   ┌─────────────────────────────────────────────────────────────────────────┐
   │  GenericAgentLoop State Machine:                                        │
   │                                                                         │
   │  PENDING ─────► GENERATING ─────► INTERACTING ─────► GENERATING ─────►  │
   │     │               │                   │                   │           │
   │     │               ▼                   ▼                   │           │
   │     │          Call vLLM           Call Game              ...           │
   │     │          for LLM             Server for                           │
   │     │          response            environment                          │
   │     │          (mask=1)            response                             │
   │     │                              (mask=0)                             │
   │     │                                                                   │
   │     └─────────────────────────► TERMINATED (when done=True or max_turns)│
   └─────────────────────────────────────────────────────────────────────────┘

3. PPO Update
   ───────────
   • compute_reward()       - Sum of per-turn rewards
   • compute_log_prob()     - Old policy log probs
   • compute_ref_log_prob() - Reference policy (for KL)
   • compute_values()       - Critic value estimates
   • compute_advantage()    - GAE / GRPO / REINFORCE
   • update_actor()         - Policy gradient step (FSDP sync)
   • update_critic()        - Value function step

4. Return metrics to client
   ─────────────────────────
   {status, global_steps, metrics{reward, entropy, policy_loss, ...}}

STARTUP COMMANDS
================================================================================

1. Start Game Server (on client machine, terminal 1):
   python -m opentinker.environment.math.math_server --port 8081

2. Start Job Scheduler (on GPU machine, terminal 1):
   cd opentinker/scripts && bash launch_scheduler.sh

3. Start Training Client (on client machine, terminal 2):
   python -m opentinker.client.math_rl \
       model_path=Qwen/Qwen2.5-0.5B-Instruct \
       num_gpus=4 \
       batch_size=16 \
       scheduler_url=http://<gpu_machine_ip>:8780 \
       interaction.config.env_host=<client_machine_ip>
